# Getting help

- **Questions** (why did that process score so high, how do I read an
  incident, does my kernel have what preflight wants): ask in
  [Discussions](https://github.com/jamesconwaydev/aegis-v2/discussions/categories/q-a).
  Somebody else is probably stuck on the same thing, and a public answer
  helps them too.
- **Bugs**: [open an issue](https://github.com/jamesconwaydev/aegis-v2/issues/new/choose)
  and pick the bug report form. If Aegis flagged something legitimate, use
  the false positive form; if it missed something, the detection report.
- **Ideas**: the feature request form, or a Discussion if the idea is still
  half-formed.
- **Security problems**: not here. See [SECURITY.md](SECURITY.md).

I run this project on my own time, so a reply can take a few days.
